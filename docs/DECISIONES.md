# Decisiones de la versión 0.1

1. La suma alquiler + expensas se compara contra el tope solo cuando ambos valores estén presentes; un aviso sin expensas queda marcado para revisión, no se supone que sean cero.
2. Las prioridades de zona y tipo sirven para ordenar resultados, no excluyen alternativas dentro de los criterios obligatorios.
3. Patio o balcón y aceptación de mascotas son filtros obligatorios. Cochera aumenta relevancia, pero no descarta.
4. El intervalo de una hora es una intención de producto; no se agenda hasta contar con una fuente expresamente autorizada y un límite documentado.
5. Playwright se declara como dependencia para futuras integraciones permitidas, pero no se importa ni ejecuta en esta versión.
